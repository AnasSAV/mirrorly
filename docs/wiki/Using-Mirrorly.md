# Using Mirrorly

## Mouse

| Do this | To |
|---|---|
| **Click** / **drag** on the screen | Tap / swipe |
| **Mouse wheel** | Scroll |
| **Drag up from the very bottom edge** | Go Home; pause before letting go for the App Switcher. Works in landscape too. |
| **Drag down from the top edge** | Notification Center (left) or Control Center (right) |
| **Right-click** | Go Home |
| **Ctrl + wheel**, or the **green button** | Make the window bigger or smaller |

## The bar

Point at the window and a bar slides in above the phone's screen. It never
covers the top edge, so Notification Center and Control Center stay
reachable.

| Button | Does |
|---|---|
| Red / yellow / green | Close, minimise, change size |
| Copied-files chip | What you copied on the iPhone: drag it out to Windows (see [[Files and clipboard\|Files-and-Clipboard]]) |
| Monitor *(iPads only)* | Use the iPad as a display (see [[iPad as a display\|iPad-as-a-Display]]) |
| Record / Camera | Record the screen, take a screenshot (see [[Screenshots and recordings\|Screenshots-and-Recordings]]) |
| Power | Disconnect, or connect again |
| Rotate | Turn the view for landscape apps |
| App Switcher, Home | As the phone's own gestures |

Drag the bar's empty space to move the window. On a small window the bar
leaves out the buttons it has no room for.

## Keyboard

Typing goes straight to the iPhone, like a Bluetooth keyboard. Ctrl stands in
for ⌘.

| Keys | Action |
|---|---|
| <kbd>Ctrl</kbd> <kbd>C</kbd> / <kbd>V</kbd> / <kbd>X</kbd> / <kbd>A</kbd> / <kbd>Z</kbd> | Copy, paste, cut, select all, undo |
| <kbd>Ctrl</kbd> <kbd>1</kbd> · <kbd>F1</kbd> | Home |
| <kbd>Ctrl</kbd> <kbd>2</kbd> · <kbd>F2</kbd> | App Switcher |
| <kbd>Ctrl</kbd> <kbd>3</kbd> | Spotlight |
| <kbd>F3</kbd> | Lock (side button) |
| <kbd>F4</kbd> / <kbd>F5</kbd> | Volume down / up |
| <kbd>F6</kbd> | Screenshot |
| <kbd>F7</kbd> | Start / stop recording |
| <kbd>F10</kbd> | Latency overlay |
| <kbd>F11</kbd> | Full screen |
| <kbd>F12</kbd> / <kbd>Shift</kbd> <kbd>F12</kbd> | Turn the view for landscape apps |

The iPhone always sends its screen upright and doesn't say when an app turns
sideways, so turn the view yourself with <kbd>F12</kbd> or the Rotate button.

## Disconnect and switch iPhones

The **power button** disconnects: Mirrorly lets go of the iPhone (its camera
and microphone are free again) and stays disconnected, even while it is
plugged in or on the same Wi-Fi, until you connect again.

While disconnected, the window lists every iPhone and iPad Mirrorly knows:

| You see | Means |
|---|---|
| 🟢 **Plugged in** | Connected by cable: click it to mirror over USB |
| **Wi-Fi, when nearby** | Connected to this PC before: click it to find it on your network |
| **Forget** | Remove its Wi-Fi pairing (plug it in again to use it) |

To use **another iPhone**, disconnect, plug it in and click it; the first
time it needs Trust and Developer Mode like the first. With two plugged in at
once, Mirrorly asks which one to mirror.

Only one Mirrorly runs at a time: starting it again brings the open window
forward.
